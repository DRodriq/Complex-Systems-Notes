# Network Science Domain

> The study of systems that can be represented as nodes connected by edges — and the discovery that many real-world networks share structural properties (scale-free degree distributions, small-world topology, community structure) that cut across their physical substrate.

## Core Concepts — Dynamic / Temporal

Topology–state–timing triad. Each of these fixes a different element and
lets the others evolve.

| Concept | One-line description | Status |
|---|---|---|
| [[dynamical-systems-on-networks]] | States evolve on a fixed network substrate (Kuramoto, epidemics) | stub |
| [[temporal-networks]] | Edges carry timestamps; time-respecting paths; burstiness | stub |
| [[adaptive-networks]] | Topology itself coevolves with node states (dynamics *of* networks) | stub |
| [[multilayer-networks]] | Multiple coupled layers representing different relationships or flows | stub |

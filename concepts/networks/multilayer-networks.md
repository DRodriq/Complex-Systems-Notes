# Multilayer Networks

## Orientation

Networks composed of multiple interacting layers — each layer a graph in its
own right — with inter-layer edges coupling nodes across layers. Used to
represent systems where the same entities participate in multiple
relationships (social + professional + kinship networks) or where multiple
types of dynamical flow share a substrate (power + information grids; actor
+ content + narrative layers in IE). Phenomena that emerge only with layer
coupling: layer-induced percolation thresholds, cascade amplification across
layers, community structure that is coherent only across layers.

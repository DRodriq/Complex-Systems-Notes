# Adaptive Networks

## Orientation

Networks in which the topology itself coevolves with the state of the nodes —
"dynamics *of* networks" rather than only "dynamics *on* networks." Feedback
between structure and state can produce phenomena (bistability, oscillations,
phase transitions) that neither static-network theory nor fixed-topology
dynamics would predict. Examples: opinion dynamics with rewiring, epidemics
where contacts are avoided, neural networks with synaptic plasticity,
ecological networks under species reorganization.

## Connections

Complementary to [[temporal-networks]]: temporal networks treat topology as a
given time series; adaptive networks treat topology as a state variable
coupled to node dynamics. Relevant to IE work where cluster and actor-network
structure evolves in response to what propagates.

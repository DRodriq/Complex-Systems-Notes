# An Introduction to Statistical Learning with Application in Python — James, Witten, Hastie, Tibshirani (2023)

> The Python edition of the widely-used statistical learning textbook, covering core ML methods from a statistical perspective with hands-on Python implementations.

## Orientation
ISLP is a canonical introductory text for statistical machine learning, covering regression, classification, resampling methods, tree-based models, SVMs, and unsupervised learning. The Python edition extends the R-based ISLR. It is practical and mathematically accessible, making it a standard reference for applied quantitative work.

## Key Ideas
- Statistical framing of machine learning: bias-variance tradeoff, overfitting, model selection
- Linear and logistic regression as foundational methods
- Regularization (Lasso, Ridge) for high-dimensional problems
- Tree-based methods and ensemble approaches (random forests, boosting)
- Unsupervised learning: clustering and PCA

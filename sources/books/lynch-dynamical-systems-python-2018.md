# Dynamical Systems with Applications Using Python — Lynch (2018)

> A computational introduction to dynamical systems theory using Python, covering continuous and discrete systems with simulation-based exploration of chaos and bifurcations.

## Orientation
Lynch's book pairs mathematical treatment of dynamical systems with hands-on Python implementation. It covers ODEs, maps, chaos, fractals, and applications in physics and biology, making it particularly useful for students who learn through computation. The Python focus distinguishes it from older MATLAB-based textbooks.

## Key Ideas
- Python as a tool for visualizing phase portraits, bifurcation diagrams, and attractors
- Discrete maps: logistic map, Hénon map, and period-doubling
- Continuous systems: Lorenz equations, van der Pol oscillator
- Fractal dimension computation
- Applications to neural networks and population models

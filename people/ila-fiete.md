# Ila Fiete

> American theoretical neuroscientist at MIT (McGovern Institute for Brain Research), working on neural codes for memory and navigation, particularly grid cells and continuous attractor networks.

## Role and Contributions
Fiete's work has helped establish the modern theoretical account of grid cells as implementing a high-capacity, error-correcting code over continuous attractor manifolds. Broader program spans population coding, memory, and the dynamics of cognitive representations.
